# 平台执行隔离与任务规范

适用于平台执行入口、项目案例、后台任务及本地回归门禁。与[平台与项目隔离规范](平台与项目隔离规范.md)、[平台身份池模型规范](平台身份池模型规范.md)及[平台序列化与反序列化规范](平台序列化与反序列化规范.md)共同使用。

## 分层职责

| 层 | 负责 |
| --- | --- |
| Core | 上下文传递工具、线程/进程资源锁、持久任务和请求去重、协作取消、历史元数据、定向测试选择与通用面板协议 |
| Pack | 哪些操作会写入、会影响哪些身份/业务资源、写开关、任务前置及业务恢复、源码到测试的映射 |
| Adapter | 实际认证、HTTP transport 和项目契约；执行控制检查通过后才发起请求 |


## 执行上下文

每个案例进入独立上下文，正常返回和异常均恢复父上下文。业务身份、token、资源目录和项目缓存只属于当前执行；禁止把线程身份写回模块默认值。缓存返回副本，切换配置须使相关缓存失效。

Core `ApiSession.request` 使用本次认证返回的局部 token 构造请求头，不能在发送前重新读取共享会话缓存。`ensure_token` 返回本次认证结果；其兼容缓存不作为并发请求的身份依据。显式 username 优先于延迟默认角色；角色引用交给 Adapter 解析，Core 不通过布尔判断提前读取身份池。认证失败不得借用缓存 token 继续发送。并发调用使用显式请求身份或各自的会话，不在 worker 中调用 `configure_cli` 改全局默认身份。



## 写资源与互斥

`execution_guard.resource_guard(exclusive=[...], shared=[...])` 使用同一项目数据根中的 POSIX 文件锁，线程、独立 CLI 和面板进程共同遵守。锁按资源键排序、非阻塞获取；任何一把锁不可用时释放已取得的锁，返回 `incomplete` 或 HTTP 409，未进入本次 runner。不同已知身份可并行。


同一执行的嵌套函数和已加入的子线程可复用有效租约；已释放或从其他 PID 继承的租约不得复用。共享锁不能在执行中升级成独占锁。该机制覆盖使用同一数据根的进程；跨主机或独立数据根不提供分布式互斥。运行期间不得删除 `.execution-locks/` 中的锁文件，删除会破坏同一文件上的互斥关系。

已有写开关、池前置及类型断言仍先行检查。资源锁和请求去重不能替代写授权、业务状态校验或请求/响应/DB 三种表示的分别验证。

## 请求标识与去重

执行 POST 使用 `requestId`（1–128 字符的非空、无首尾空白字符串）。相同标识、任务类型及原始参数指纹返回原任务或已存结果；同标识不同参数拒绝为 HTTP 409。指纹包含原始 JSON 类型，`"0.01"` 和 `0.01` 不视为同一参数。存储摘要，不存入指纹原文。

共用面板客户端为 JSON POST 生成标识；网络失败或服务端 5xx 后，用户重试相同参数沿用该标识。浏览器持久区只保存参数摘要和标识，不保存明文凭据，也不自动重发写操作。无标识的旧调用仍可执行，但没有持久去重保证；新代码必须传递标识。

后台提交返回 `jobId`，其后只查询任务，不再次提交。同步执行在进行中的重复请求返回 `pending`、`executionId`；查询 `/api/execution/job?id=<id>` 获取状态。同一标识的失败、取消或中断任务也不重放。核验业务状态后决定重新执行时使用新标识。

## 持久任务和终态

任务存于当前项目的 `execution_jobs.db`，默认超时 1200 秒，可通过 `timeoutSeconds` 设置有限正数，上限 86400 秒。执行入口、HTTP 客户端、Pack 的操作及等待循环均检查控制状态。

| 状态 | 含义 |
| --- | --- |
| `queued` / `running` | 排队 / 正在执行 |
| `cancel_requested` | 已请求停止新增业务操作，等待当前操作与恢复完成 |
| `done` | 任务正常完成；具体断言仍以结果中的案例状态为准 |
| `failed` | 执行或恢复失败，保留错误 |
| `incomplete` / `skipped` | 前置缺失、资源冲突或覆盖缺口，不能计为通过 |
| `cancelled` / `timed_out` | 已协作终止 / 达到时限，不计为通过 |
| `interrupted` | 所属进程已结束或 PID 已复用，需要核验业务状态 |

`POST /api/execution/cancel` 传 `{ "id": "任务标识" }`。排队任务立即取消；正在运行的任务请求取消；终态结果不变。协作取消不能撤销已完成的业务操作，也不能强制中止正在等待返回的 HTTP 请求。已有 transport 超时仍生效。


业务写入的关联、快照和恢复属于 Pack。Core 仅传递取消上下文和资源租约。Pack 必须记录本次操作实际产生的资源标识，先完成恢复再响应取消；无法确定关联或恢复失败时明确报告，不猜测其他业务资源。请求、响应和对账表示由所属 Pack 契约确认，Core 不指定业务字段或 DTO。

启动时核对任务所属 PID 和进程启动时间。仍在运行的所属进程不改变状态；已结束任务标记 `interrupted`，禁止自动重放写操作。已完成任务默认保留 7 天，超过 1000 条时清理较旧记录；最近 24 小时的去重记录与全部活跃任务始终保留，因此 1000 条是软上限。


长任务只通过持久提交入口创建，观察进度不得重复提交；观察者断开不自动改变业务状态。业务并发 worker、指标采集和报告写入由 Pack 等待与收尾，不能在仍有业务工作时提前释放锁。参数转换必须排除 bool、非有限值和越界数值。身份列表有错误时拒绝，不删去坏项后改用其他身份。

面板等待有时限，并明确显示取消、超时、中断和失败；连续查询失败会停止自动等待并提供继续查询。任务标识保存在当前页面会话中，刷新后可恢复查询，不能因等待结束或未知状态显示通过。

## 历史与复现


旧历史迁移后 `executionMetadata` 为 `{}`，不伪造旧运行的版本证据。面板保存历史失败须显示 `historySaved=false` 和错误，业务 runner 不能因此再执行一次。历史元数据也由非面板调用的历史入口补齐；调用者应主动传入实际运行选项。

这些元数据帮助定位运行版本，不证明线上部署或外部数据快照相同，也不是凭据备份。响应仍须按原始 JSON 类型先校验，再计算或对账。

## 定向回归门禁

Core 清单为 `resources/targeted-regression.json`；项目清单通过 manifest `regression_manifest` 声明，组名以 Pack ID 为前缀。每组显式列出源码匹配、Python 测试模块和 Node 测试文件。新增/变更 Python、JavaScript、shell 或 HTML 源码没有映射时门禁失败；变更测试文件自动加入选择。禁止改为整库 discover。


```bash
# 先审查受影响范围
python3 scripts/targeted_regression.py --changed --plan
# 运行选中的离线测试，并保存结果
python3 scripts/targeted_regression.py --changed --report /tmp/platform-regression.json
# 只核验执行组件
# 所有本地静态门禁与受影响回归；提交 hook 使用 --staged
```

执行器只加载清单中的测试模块，并以全新 Python/Node 进程运行。清理调用者环境，仅保留执行所需的系统变量、当前 Pack、已解析的声明输入路径；`PLATFORM_ENV_FILE=/dev/null`，业务 URL 使用 `offline.invalid`，账号池、任务、锁、历史和产物使用临时目录。Pack 可在回归清单 `offline_environment` 声明显式 `synthetic-offline-` 值的夹具，禁止覆盖平台隔离配置；不加载、复制真实账号池或凭据。缺少测试夹具应修复测试，不借用本地池让回归通过。

Python/Node 的网络与文件防护在测试载入前安装，子进程即使显式传空 env 也继承 guard、禁用真实环境文件及重定向数据根。常用 socket、DNS、HTTP/fetch、文件访问的被拦截尝试记入临时日志；异常即使被测试捕获仍使门禁失败。macOS 用 `sandbox-exec` 阻断整个进程树的网络及真实源码目录写入、凭据/池读取；Linux 提供 bubblewrap 的只读根、独立网络与临时目录方案，本轮未在 Linux 执行。缺少原生后端或 worker 未生成结果时停止并报告 incomplete，不能降级为零测试通过。

该离线执行环境覆盖显式选中的可信测试，不是供恶意任意代码使用的安全服务；原生防护覆盖的绕过访问未必计入语言层尝试数。当前只验证本机 macOS；Windows 不支持。原生沙箱需正常本地进程权限，在已经限制创建原生沙箱的外层运行环境中可能启动失败；失败时仍保持门禁关闭。Python 与 Node 均结束后才清理临时目录，输出分别列出测试数、失败/错误、网络/文件拦截次数、隔离后端与数据清理状态。禁止运行全量业务案例、全部 SAFE/LIVE 或全部 unittest。


任务结果须区分通过、失败、未执行与数据变更。用真实池指纹、身份/场景数及真实历史条数核验离线测试未修改业务数据。

## 通用上下文与复现补充

Core 不按路径、字段或 OAS 猜业务资源。Pack 的 execution_resources 钩子显式声明业务锁。线程池使用 submit_with_context 或 context_callable，每个任务独立复制 Context；父调用必须等待所有 worker 与恢复完成才释放资源。脱离父生命周期的任务使用 start_background_job，自行获取资源锁，不能借用已经释放的父租约。

执行来源包括当前 Pack、Core/Adapter 源码、所声明契约、身份池指纹与脱敏选项。指纹不复制账号和凭据，不证明外部服务部署版本相同。未提交源码也应改变源码指纹；历史保存失败不能触发第二次业务 runner。

Core 资源与 Pack 的 OAS/schema 输入均须登记回归映射。定向回归只执行受影响组；来源缺少映射、测试异常或实际受保护资源访问均失败，不用零测试或全量运行掩盖问题。
