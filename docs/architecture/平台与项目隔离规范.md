# 平台与项目隔离规范

每个进程只装载一个项目 Pack。Core 提供机制，Pack 提供业务策略，Adapter 提供项目认证、响应信封和解码。Pack 是受信任代码，装载隔离不是任意代码的安全沙箱。

## 装载

`PLATFORM_PACKS` 只允许一个 ID；为空时使用唯一 default。ID 必须等于 packs/<id> 目录名。bootstrap 先经静态归属校验再导入。启动失败须修复并重启，不继续使用半初始化进程。cases 放入 Pack 自己的 case_dirs，使用完整包路径导入；禁止导入其他 Pack。源码、adapter_files、面板入口不能通过符号链接逃出仓库。Core 不直接导入业务模块。

Core Python 文件和本地依赖登记 resources/platform-core-files.json；common 只放已登记通用组件。业务 helpers、工具、Adapter、schema、契约、知识库与数据配置归所属 Pack。

## 配置与数据

PLATFORM_ENV_FILE 未设置时读 .env.local，相对路径以仓库为根，/dev/null 禁用文件。已有进程环境优先（含显式空值），缺少键才从纯文本文件补入；文件不执行 shell，不能重定向自身 selector。项目默认值来自 config_defaults；凭据只放忽略的本地配置或外部密钥来源。时区使用 TZ=Asia/Shanghai。

每个项目独立 PLATFORM_PACK_DATA_DIR、PLATFORM_ARTIFACT_ROOT、环境文件和 PLATFORM_PANEL_PORT。端口允许 1–65535，发行 demo 使用 8801。历史落入数据目录 run_history.db；池位置通过 identity_pool_file 配置。项目路径覆写必须显式，子路径解析不得逃出资源根。历史、账号池和证据不会在发行时复制。

PID、日志放 .run/<pack>-<port>/，启动器仅操作标签和仓库匹配的服务，拒绝操作其他项目进程。切换 Pack 或 manifest 修改后重启；案例文件可热重载。

## 可选能力

resource_pool 默认关闭，类别、显示字段、关系、登录类别、登记和夹具策略由 Pack 声明。panel_services、panel_extension、catalog_extension、cli_tools 提供可选业务扩展；缺少能力返回 incomplete，不从其他项目借用实现。shared_core_services 只能引用允许的通用服务。扩展方法与示例见接入手册。

## 验证

```sh
python3 scripts/check_platform_isolation.py --json
python3 scripts/verify_project_pack.py --pack sample_app --mock-smoke
PLATFORM_ENV_FILE=/dev/null python3 scripts/targeted_regression.py --group onboarding --group isolation
```

静态检查不替代真实业务契约验证，mock smoke 仅验证装载、执行与结果链路。离线定向回归使用临时数据和原生子进程保护，不运行全量业务案例。
