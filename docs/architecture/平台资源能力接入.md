# 平台资源能力接入

共享工作台提供本地字体、四套主题、案例执行、历史与诊断框架。资源池是可选能力，默认 demo 关闭，不创建固定业务类别。

关闭配置：
```json
{"resource_pool":{"enabled":false}}
```

项目可在 pack.json 自定义类别：
```json
{"resource_pool":{"enabled":true,"title":"设备资源","categories":[{"id":"device","label":"测试设备","storage":"identities","display_fields":["serial_number"]},{"id":"service_account","label":"服务账号","storage":"identities"}]},"identity_requirements":{"device":["probe"],"service_account":["reader"]}}
```

分类 id 使用小写字母开头的字母、数字或下划线，不可重复。storage 支持 identities、scenarios、fixtures，后两类集合各允许声明一次，名称和标签自定义。display_fields 只影响脱敏展示，密码和 token 仍脱敏；关闭时不读池文件、不运行审计。未声明类别不能通过登记接口写入。

业务关系通过 relationship_fields / distinct_roles 声明。登录默认类别通过 Pack 的 PLATFORM_DEFAULT_CLI_CATEGORY / PLATFORM_DEFAULT_MGR_CATEGORY 配置。登记限制和别名策略通过 identity_registration_policy.existing_only / identity_alias_policy 声明。

负向夹具分类通过 identity_requirements.notes.fixture_name_pattern 声明，生成值来自 fixture_templates 或所属 Pack 注册的工厂。Core 不根据字段名字猜业务 ID、金额或账户。真实业务 Adapter 与资产由接入项目自行提供。

工作台支持 Claude、Night、Studio、Console，资源入口和分类随当前唯一 Pack 的声明变化。
