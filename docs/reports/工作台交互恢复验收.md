# 工作台交互恢复验收

日期：2026-10-09。对照原平台业务面板的通用交互结构，只读检查参考文件，未修改参考项目或业务源项目。

## 原因

独立平台采用简化 demo 工作台，没有继承原业务面板的首页、导航树、工作标签与筛选体验。首次文档页面又使用不同布局，导致平台基础交互分裂。

## 恢复范围

- 首页模块入口、分组导航展开收起、全部用例入口、返回总览。
- 工作台和文档共用侧栏与顶部工作标签；标签可切换和关闭，在本浏览器会话保留。
- 侧栏拖动调宽、键盘调整和双击复位；宽度本地保存。
- URL hash 保存分组，刷新仍停留原分组。
- R/F/D/E/LIVE 系列筛选、关键词搜索、用例详情展开、当前分组 SAFE 执行入口。
- 保留后台任务、取消和恢复查询；增加执行结果详情。
- 白皮书使用统一字体、正文内目录、标题与表格；手册继续沿用同一外壳。

通用界面不是业务 Pack 的替代。当前 demo 无业务专属查询、资金操作、造数或压测，LIVE 执行仍未开放；未执行真实业务操作，也不声明业务面板已全部迁移。

## 验证

通过：浏览器首页进入 demo 分组；F 系列筛选显示零条、全部筛选恢复；单条 DEMO-R01 离线执行结束；标签切换到白皮书；返回分组并刷新保持 URL；侧栏键盘调宽从 260px 到 270px；关闭白皮书标签后剩余两个标签；浏览器未报告脚本错误。白皮书截图检查通过。

通过：项目隔离和中性发行检查、4 项发行运行测试、JavaScript 语法与 diff 空白检查。

未执行：真实业务案例、全量案例、LIVE、业务专属工具验收及不同操作系统验证。

## 数据变更

源码与文档修改；新增共享工作台 CSS/JS。单条本地 mock 执行产生本平台任务、历史与证据记录，浏览器会话保存工作标签与侧栏宽度。无真实业务数据写入，未提交或推送。

## 完整结构补齐

按参考工作台结构进一步恢复首页左右布局：左侧为可折叠分组及接口/数量列表，右侧为统计、工具、洞察与文档分区。用例页采用用例、子类、描述、参数、预期、执行、结果七列表格，运行栏保留 SAFE、LIVE、重跑失败；没有 LIVE 或失败用例时对应入口禁用。单条 LIVE 和批量 LIVE 的实际写入前有界面确认，本轮未执行 LIVE。

巡检、历史、白皮书、手册统一侧栏及工作标签。系列、搜索、失败过滤及执行结果按项目在当前浏览器会话保存。分组折叠状态也保存。业务专属清理不虚构通用 API。
