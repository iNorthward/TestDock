# 底座扩展改造交付说明

日期：2026-10-21。范围：TestDock API 1.1 的请求准备、能力采用清单与可组合工作台组件。

✅ 完成：三项扩展已实现，兼容入口、使用配方、定向回归、合成接入与浏览器验收已覆盖。

## 需关注

- 验收使用临时合成 Pack、自有回环服务和浏览器生成数据，不证明真实业务认证、资金操作、数据库容量或性能已经通过。其他独立发行的升级和业务迁移须另行执行。
- 主定向回归有 10 项跳过：离线隔离环境按设计跳过 6 项真实回环 HTTP 与 3 项回环停止检查，另 1 项缺少可选 PyMySQL 依赖。跳过不计为通过；自有接入和扩展回环另行验证。
- 浏览器复制检查完整原始文本传给原生写入 API 并成功返回；浏览器不允许程序化读回剪贴板，未声称已核验操作系统剪贴板内容。拒绝分支为显式注入的合成故障。
- 能力清单记录可信执行者提供的事实与适用范围，不是远端服务或已加载字节码的加密证明。默认 demo 与新 Pack 的采用声明初始仍为未执行。

## 已完成

| 项目 | 最终行为 | 兼容与迁移 |
| --- | --- | --- |
| 请求准备与签名 | 正文只编码一次，冻结 method、URL、headers 与 bytes 后签名，默认网络与 prepared transport 消费同一表示；无正文、空正文与 JSON null 分开；签名失败不发请求，无重定向和隐式重放 | 旧 transport 继续接收 Python data；新路径显式选择编码器、签名器或 prepared transport；算法、查询规范和精确金额策略仍归 Adapter |
| 能力采用清单 | doctor、任务状态、平台 API 和默认面板共享 9 项能力的采用方式、必需性、验证事实、范围和证据；声明、Core/UI、Adapter、报告、原授权变化后失效；运行源码漂移显示重启要求 | 原六个接续任务不变；旧 Pack 未声明可继续装载并显示待补充；必需能力按明确 required_scope 验收；真实只读沿用已有授权证据 |
| 工作台交互组件 | 局部反馈、原任务恢复、投影详情弹框、版本化白名单表单、作用域及乱序保护列表、不透明游标、精确文本与显式时区、复制反馈；两种合成页面复用同一组件 | 不引入前端框架；沿用执行与安全客户端；业务字段、幂等、结果含义、分页和敏感字段选择由 Pack 明确提供 |

平台 API 从 1.0 增至 1.1，新增 prepared_requests、capability_adoption、workbench_components。旧版本范围保持正常兼容；新生成 Pack 声明 1.1 和能力采用信息。新资产、测试、样例与验收器已登记并随独立发行输出。

默认面板新增采用表及证据范围。390px 下采用表只在本地容器横滚；修复工作台页头负外边距造成的页面溢出。

## 使用入口

- [请求准备与签名](../guides/请求准备与签名.md)：公共 API、正文三态、精确编码配方、头与重定向约束、旧 transport 迁移。
- [能力采用清单](../guides/能力采用清单.md)：manifest 声明、验证前上下文、报告摘要引用、真实只读授权与失效规则。
- [工作台交互组件](../guides/工作台交互组件.md)：六类组件、业务职责、两个合成页面及可重复浏览器验收器。
- [接入与运行操作](../onboarding/AGENT_OPERATIONS.md)：API 1.1 的采用和验收步骤。

浏览器验收器额外需要本机 agent-browser CLI 与 Chromium；它是可选验收工具，不增加平台正常启动依赖。

定向运行方式：

```sh
PLATFORM_ENV_FILE=/dev/null PYTHONDONTWRITEBYTECODE=1 python3 scripts/targeted_regression.py --group transport --group onboarding --group execution-ui --group isolation --group distribution --group gate --file tests/test_execution_provenance.py --report artifacts/foundation-extensions/targeted.json
PLATFORM_ENV_FILE=/dev/null PYTHONDONTWRITEBYTECODE=1 python3 scripts/accept_project_integration.py --report artifacts/foundation-extensions/integration.json
PLATFORM_ENV_FILE=/dev/null PYTHONDONTWRITEBYTECODE=1 python3 scripts/accept_foundation_extensions.py --report artifacts/foundation-extensions/synthetic-extensions.json
```

禁止运行全量业务案例，以上接入验收仅使用自有回环服务。受限环境若不能启动离线隔离 worker 或监听回环端口，必须保留 incomplete，不能绕过门禁或报告通过。
